## Shared integration points

- Keep API and Browser command protocol/version metadata aligned in one release.
- All caller-supplied tenant/device/actor identifiers are non-authoritative; derive and enforce them at the API boundary.
- Do not retry vendor/CRM side effects on transport timeout unless the selected adapter's idempotency contract has been verified for that operation.
- Keep localized strings in existing catalogs and preserve widget/route contracts.
- Do not run local application tests, builds or lint; static source, docs, JSON, manifest/version and PHDK coherence checks remain permitted.
- Git delivery is normal versioned branch → scoped PR → merge → exact remote readback. No Actions, force-push, provider CLI/API/dashboard write, live customer data, live call or secret inspection.
